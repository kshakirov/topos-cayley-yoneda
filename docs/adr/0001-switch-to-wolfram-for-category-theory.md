# ADR 0001: Переход с Idris 2 на Wolfram Language для исследования ТК

## Статус
Принято (Accepted)

## Контекст
Первоначальный прототип разрабатывался на языке Idris 2 с целью строгой верификации законов категорий через систему зависимых типов. Практика показала, что накладные расходы на отладку типов и доказательство базовых равенств составляют до 95% рабочего времени. Это критически замедляет проверку концептуальных математических гипотез (вложение Кэли, Лемма Йонеды).

## Решение
Принято решение перенести исследовательскую среду на Wolfram Language (Wolfram Engine + Jupyter Lab). 

## Обоснование
1. Wolfram Language является мощным символьным процессором: код и данные в нем едины (абстрактные морфизмы можно преобразовывать как символьные выражения без явного вычисления).
2. Наличие встроенного графового и топологического аппарата исключает необходимость написания шаблонного кода (boilerplate) для визуализации структур.

## Последствия
- Потеря строгой верификации типов на этапе компиляции (законы категорий теперь проверяются символьно-алгебраическими тестами).
- Скорость проверки гипотез и реализации функторов увеличивается в разы.
