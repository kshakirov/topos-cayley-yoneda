# ADR 0002: Моделирование категории ZCat и Функтора Кэли

## Статус
Принято (Accepted)

## Контекст
Необходимо спроектировать минимальную модель для верификации теоремы Кэли о представлении абстрактной структуры через функции сдвига множества.

## Решение
Реализовать в Wolfram Language модель аддитивной группы целых чисел как категории `ZCat` и построить Функтор Кэли в категорию множеств `Set`.

## Спецификация модели
1. **Объекты ZCat:** Одноэлементное множество `Obj = {"OnlyThis"}` (плейсхолдер).
2. **Морфизмы ZCat:** `Morph = Integer` (все целые числа являются стрелками-петлями).
3. **Композиция:** Ассоциативная операция сложения `zCompose[f_, g_] := f + g`.
4. **Идентичность:** `zId = 0`.
5. **Функтор Кэли (cayleyFunctor):** 
   - На объектах: `F["OnlyThis"] = Integers` (множество целых чисел).
   - На морфизмах: `F[n_] := Function[x, x + n]`.

## Критерий успешности (Логический тест)
Модель считается корректной, если символьный тест подтверждает закон функториальности (сохранение композиции):
`cayleyFunctor[zCompose[f, g]][x] == cayleyFunctor[g][cayleyFunctor[f][x]]`
