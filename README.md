# topos-cayley-yoneda 🌀

> **Символьная деформация категорий: от платоновской статики к динамике вычислений.**

Проект посвящен интерактивному исследованию, визуализации и строгому символьному доказательству **вложения Кэли** и **Леммы Йонеды** с использованием вычислительного движка **Wolfram Language**.

## 🛠️ Стек и Окружение
- **Ядро:** [Wolfram Engine](https://wolfram.com) (Локальное математическое ядро вычислений)
- **Холст:** [Jupyter Lab / Notebook](https://jupyter.org) (Интерактивная среда)
- **Язык:** Символьный Wolfram Language (без использования капризных внешних пакетов)

## 📁 Структура проекта
- `README.md` — Манифест и инструкция по запуску.
- `docs_rd.md` — Бортовой журнал исследований (R&D) и математический аппарат.
- `ZCat_Simulation.ipynb` — Интерактивный блокнот с кодом категории `ZCat` и Функтора Кэли.
