# Issue #2 — Первый живой эксперимент: морфизм как символьное выражение

GitHub: https://github.com/kshakirov/topos-cayley-yoneda/issues/2

## Задача

Начинаем с самого малого — без библиотеки категорий и без большой архитектуры.

Хотим руками посмотреть, как Wolfram работает с непрозрачной символьной формой и как из неё постепенно рождается вычисление. Берём выражение `Morphism[name, A, B]`: для Wolfram это голова и аргументы, а для нас — заготовка морфизма `name : A → B`.

Дальше исследуем pattern matching, источник и цель морфизма, а затем пробуем построить композицию только для совместимых стрелок.

## Итог текущего сеанса

- Запустили Wolfram REPL из терминала и внутри Emacs.
- Настроили отправку выделения и целого буфера в REPL.
- Увидели выражение как `Head + arguments`.
- Представили морфизм формой `Morphism[name, A, B]`.
- Через шаблоны достали его источник и цель.
- Дошли до условного правила композиции и смысла `/;` (`Condition`).

## Следующий шаг
